# SecureAid – Cloud-Native Emergency Donation Platform

## Project Description
SecureAid is a secure, concurrent, and cloud-ready Java Spring Boot REST API for tracking emergency donations. It focuses on secure coding, data encryption, and transparent, auditable donation records to support communities affected by disasters in Ghana, Africa, and globally.

## Features
- Secure donation submission and tracking
- Data encryption for sensitive donor information
- Digital integrity verification of donation records
- Concurrent request handling
- Ready for AWS deployment

## Getting Started (Local Development)

### Prerequisites
- Java 17 or higher
- Maven 3.8+

### Build the Application
```sh
mvn clean package
```

### Run the Application
```sh
mvn spring-boot:run
```

The API will be available at: `http://localhost:8080/`
